# Music Bot for Discord

A music bot for Discord servers. Invite the bot using the link below.

[**Invite the bot**](https://discord.com/oauth2/authorize?client_id=1563898963722109019)

## About

Music Discord Bot is a Discord bot intended for use in Discord servers. Plays music from YouTube, Spotify, and Yandex Music.

## Add the bot to a server

Use the [invite link](https://discord.com/oauth2/authorize?client_id=1563898963722109019) and select a server where you have permission to add applications. Review the requested permissions before authorizing.
